# Aragon (working title)

A browser remake of *Sword of Aragon* (SSI, 1989): run your towns, raise troops, march across the province and fight turn-based hex battles against the orcs of Gharzak Hold.

```bash
npm install
npm run dev     # play at http://localhost:5173
npm test        # rules tests
npm run build   # type-check and build to dist/
```

See [docs/design.md](docs/design.md) for what's in v0.1, what's next, and how the code is laid out.

The game autosaves to your browser after every action. Use **New game** to start over.
